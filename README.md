# Countdown Manager для iPhone

Нативное приложение на SwiftUI для iOS 18 и новее. Восемь экранов из [макета Figma](https://www.figma.com/design/1fS2Tu3jWOjlXt3yD35stw/Untitled?node-id=0-1) используют светлую и тёмную палитры [Countdown Manager для macOS](https://github.com/MonolitST/CountdownManager).

## Запуск

1. Откройте `CountdownManagerMobile.xcodeproj` в Xcode 26.
2. Выберите схему `CountdownManagerMobile` и симулятор iPhone.
3. Запустите приложение через **Product → Run**. Для запуска на устройстве выберите одну команду подписи для приложения и его расширений. Для **CountdownManagerMobile** и **PlanShareExtension** используйте зарегистрированную в этой команде группу `group.com.monolitst.CountdownManagerMobile`.

Чтобы открыть приложение с примерами из макета, добавьте аргумент запуска `-demo-content` в **Product → Scheme → Edit Scheme → Run → Arguments**. В этом режиме изменения хранятся до закрытия приложения.

## Данные и уведомления

Приложение создаёт `planner.sqlite` при первом запуске. Планы, пункты чек-листов и напоминания хранятся в отдельных таблицах. В `settings` сохраняются тема, погода и город, уведомления и длительность фокуса. Активный таймер хранится в `focus_session`. Прошедшие планы остаются доступны. Уведомления доставляет iOS после выдачи разрешения. Когда слишком много интервалов для постоянного расписания iOS, приложение планирует ближайшие срабатывания и пополняет расписание при следующем открытии.

Фото и PDF сохраняются отдельными файлами в общей папке приложения и Share Extension. Таблица `plan_attachments` хранит метаданные и ссылки. Вложения можно добавить в редакторе или через **Поделиться → Countdown Manager**. Приложение откроет выбранный план при следующем возвращении в него.

Погоду и поиск городов предоставляет [Open-Meteo](https://open-meteo.com/). Данные прогноза доступны на условиях [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). PT Serif включён на условиях [SIL Open Font License](CountdownManagerMobile/Resources/PTSerif-OFL.txt).

## Язык и город

Интерфейс доступен на русском и английском. Он учитывает язык приложения в настройках iOS. Названия и заметки, которые пользователь уже сохранил, остаются на исходном языке.

В **Настройки → Город** можно включить автоматическое определение или найти город по названию. Для автоматического режима приложение запрашивает доступ к геолокации при использовании. Приблизительные координаты отправляются в Open-Meteo для получения прогноза. Если местоположение недоступно, приложение предлагает выбрать город вручную или использует ранее выбранный город.

## Архитектура

Приложение использует MVVM. Модели и правила изменения данных находятся в `Domain`. `PlannerViewModel` обрабатывает действия пользователя и работает с хранилищем через протокол `PlannerRepository`. `SQLitePlannerRepository` в `Data/Persistence` хранит записи в SQLite через GRDB и сохраняет изменения одной транзакцией. `PlansViewModel` и `RemindersViewModel` подготавливают списки для SwiftUI. `NotificationViewModel` управляет состоянием разрешений, а `NotificationScheduler` регистрирует уведомления в iOS.

Тесты Swift Testing проверяют сохранение изменений в SQLite, откат при ошибке, расписание уведомлений и переход на летнее время. Они запускаются через **Product → Test** в схеме `CountdownManagerMobile`.
