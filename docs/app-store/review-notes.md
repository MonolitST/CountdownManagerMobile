# App Review Notes · English

Скопируйте текст в **App Review Information → Notes**. В контактных полях укажите имя, рабочую почту и телефон ответственного за выпуск.

```text
Countdown Manager is an iPhone and iPad app for counting down to important dates and preparing for them. It opens without an account. You can complete onboarding or tap Not now to reach the Plans tab.

1. Create a plan with a future date and add a checklist item. Use Add attachment in the plan editor to attach a photo, PDF, or web link. Save the plan and open it to view the checklist and attachments.
2. Share a PDF from Files or a web link from Safari. Choose Countdown Manager in the iOS share sheet, select the saved plan, and tap Save to plan. Return to Countdown Manager to open the plan with the attachment.
3. Open Reminders and create a one-time reminder or an interval reminder. Allow notifications if you want to test their delivery.
4. Open a plan and start the focus timer from its timer card. On iPad, you can pause and resume the timer. With Live Activities enabled, the timer can appear on the Lock Screen and in the Dynamic Island on a supported iPhone.
5. To test the optional forecast, go to Settings, turn on Show weather, and select a city. The city can be chosen manually. If you opt to use your location, the app requests location while in use and sends rounded coordinates to Open-Meteo to request the forecast.
```
